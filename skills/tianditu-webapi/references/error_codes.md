# 错误码参考

## 地名搜索 V2.0 状态码（status.infocode）

| 返回码 | 英文描述 | 定义 | 常见原因 |
|--------|---------|------|---------|
| 1000 | OK | 服务正常 | 请求正常 |
| 2001 | Parameter Invalid | 请求参数错误 | 参数名拼写错误 |
| 2002 | Parameter formal error | 请求参数格式错误 | 参数值不符合 JSON 标准（postStr 未编码/非合法 JSON） |
| 2003 | Parameter missing | 缺少必填参数 | 缺少该接口必填参数 |
| 2004 | Parameter wrong value | 枚举值错误 | queryType/style 等枚举取值错误 |
| 2005 | Parameter wrong latlon | 经纬度数据错误 | 传入的经纬度错误 |
| 2006 | Parameter latlon slop over | 经纬度越界 | 传入经纬度数量超过 20 个点 |
| 2007 | Parameter count slop over | 请求数据量溢出 | start/count 取值问题，或总数据条数超过 500 |
| 3000 | Server error | 服务器出错 | 后台服务器异常 |
| 3001 | No data found | 没有找到数据 | 未找到任何结果 |

## 权限类型错误（全接口通用，实测）

| 返回码 | 含义 | 说明 |
|--------|------|------|
| 301012 | 权限类型错误 | 响应形如 `{"code":301012,"msg":"权限类型错误","resolve":"Key权限类型为:浏览器端，请使用浏览器访问！"}`。**Key 类型与调用场景不匹配** |

**实测机制（User-Agent 判定场景）：**

| 调用场景 | 服务端 Key | 浏览器端 Key |
|---------|-----------|-------------|
| curl 等服务端调用（默认 UA） | ✅ 正常 | ❌ 301012 / 403 |
| 浏览器 JS 调用（Chrome UA） | ❌ 403 | ✅ 正常 |

- **服务端调用（本 skill 的 curl 请求）必须用「服务端」类型 Key**
- 浏览器端 Key 仅在带浏览器 UA 的调用中有效（浏览器端 Key + 浏览器 UA 实测可调通 Web 服务 API）
- 排查：`301012` 时提示用户到[控制台](https://cloudcenter.tianditu.gov.cn/center/development/myApp)确认应用类型与调用方式匹配

## 调试技巧

- `2002`：检查 postStr 是否为合法 JSON 且已 URL 编码（用 `--data-urlencode`）
- `2003`：对照对应 queryType 的必填参数清单（见 search_v2.md 查询类型表）
- `2004`：检查 queryType（1/2/3/7/10/12/13/14）、style（0-3）等枚举值
- `2006`：多边形坐标点数超限，精简 polygon
- `2007`：start 0-300、count 1-300，总数不超过 500
- `3001`：换关键词、扩大范围或去掉 dataTypes 再试
- `301012`：Key 类型与调用场景不匹配——curl 调用必须用服务端类型 Key（见上表实测矩阵）
